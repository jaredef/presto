# PRESTO Cookbook — Master Plan

**Status:** IN PROGRESS
**Date:** 2026-04-05

## Objective

Working implementations of every major React ecosystem feature, built at the correct constraint depth. Each recipe is a self-contained page exercising the full module kit.

## Phases

### Phase 1: Surface Recipes (Layer 0)
- CRUD app (list, detail, create, edit, delete)
- Content site with search + pagination
- Auth-gated pages with role-based rendering

### Phase 2: Shallows Recipes (Layer 1)
- Live search with inline results (htmx)
- Tab navigation without page reload
- Load more / infinite scroll

### Phase 3: Wading Depth Recipes (Layer 2)
- Form with client validation + optimistic submit
- Sortable filterable data table
- Drag-and-drop kanban board

### Phase 4: Mid-Depth Recipes (Layer 4)
- Real-time notification feed
- Collaborative presence indicator
